# Week 8 — Task 8: Libraries and File Handling
**B3 date:** 30 September 2026

Demonstrates adding an external package, accessing app documents with `path_provider`, and creating, writing, and reading a text file with `dart:io`.

Add under `dependencies:` in `pubspec.yaml`:
```yaml
path_provider: ^2.1.5
```
Run `flutter pub get`, copy `main.dart` into `lib/main.dart`, then run locally with `flutter run`. Actual device file operations do not run in DartPad.
